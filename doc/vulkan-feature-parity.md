# Vulkan Feature Parity

更新时间：2026-07-04

本文记录 Vulkan 后端相对通用 renderer 契约的当前状态。状态只按已实现代码和自动化验证记录填写；没有自动化或明确验收证据的能力不标为完成。

## 自动化基线

- `ctest --test-dir build/dev-mswin -C Debug -R Vulkan.* --output-on-failure --timeout 300`：37/37 通过。
- Vulkan runtime/golden tests 使用 CTest `FAIL_REGULAR_EXPRESSION "\\[Vulkan\\]"`，validation layer 错误输出会使测试失败。
- 2026-07-04 路径复核：tracked 修改和 untracked 新增 shader 均已纳入复核；Vulkan 固定/overlay/RT/compute 管线 shader 继续走通用 GLSL->SPIR-V；`RawShaderMaterial` raw-compatible、`seascape_demo`、`Sky`/`Water`/`GrassField` visible fallback 均属于手写特例，不再作为最终 Vulkan ShaderMaterial 路径；后续 GLSL 能完整复用时走通用 GLSL->SPIR-V，不能完整复刻时走 Slang->SPIR-V。
- 2026-07-03 shader ID 语义复核：G-buffer `ids.x` 保存 material/surface id，`ids.y` 保存 geometry instance id；RasterFirst 水体/geometry lookup 使用 `ids.y`，denoise/clearcoat 邻域和 deferred material lookup 使用 `ids.x`，raygen silhouette 检测使用 `ids.y`。

## 后续压力矩阵 / 无独立 example 覆盖

- VSM shadow map 的完整 example 级验收和更高阶参数/空间矩阵
- PhysicalMaterial 高级贴图组合：当前 threepp `MeshPhysicalMaterial` 接口没有 sheen/iridescence map 字段

`logarithmicDepthBuffer` 暂不列为 Vulkan 缺口：GL capability 当前固定为 false，Canvas/Renderer 没有 public enable API；只有新增公共契约后才需要 Vulkan parity 验收。

这些项不作为当前 Vulkan parity 阻塞。后续若要把压力矩阵提升为发布门禁，需要先定义有限组合范围，再补充测试或经用户批准改造 existing examples。
